# Aaditi Yogalaya

A mobile-first single-page site for Aaditi Yogalaya, built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Import this repository in [Vercel](https://vercel.com/new).
2. Select the **Vite** framework preset (normally detected automatically).
3. Click **Deploy**. No environment variables are required.

## Replacing the founder placeholder

The temporary founder block is in `src/App.tsx` under `portrait-placeholder`. Replace it with an `img` element when Salita's approved portrait is available.
